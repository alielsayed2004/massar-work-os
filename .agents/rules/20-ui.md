# UI rules (Massar Design System v1)

- Colours, fonts, spacing, radius: **only** `var(--…)` tokens from `globals.css`. No HEX, no rgba, no gradients, no new fonts. Palette: Massar Green, Bone, Ink, Clay (≤3%, attention only), Stone (dividers only, never text on Bone).
- Reuse `s.*`, `StatusBadge`, `Flash`, `Empty` from `src/components/ui.tsx`. A status is always text + mark + approved colour, never colour alone.
- Never show a bare "Approved": use «معتمدة داخليًا» / «معتمدة من العميل».
- One primary action per surface. Tables over card grids. No dashboards/charts unless a specific role needs them for a daily decision.
- RTL page (`dir="rtl"`); wrap Latin, dates and IDs in `<bdi>`. Logical CSS (`paddingInline`, `insetInlineStart`).
- Every field has a visible `<label>`; placeholders are not labels. Touch targets ≥ 44px.
- Forms post to server actions and show results through `?error=` / `?ok=` + `<Flash>`. Pages that read `searchParams` need `export const instant = false;`.
- Errors: Ink text with a Clay side marker — never small Clay text on Bone.
- No AI images. Use the official logo `/image/massar_logo.svg` (Bone) on Green only.
