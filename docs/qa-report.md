# تقرير الجودة — بعد مراجعة 7 أكتوبر 2026

> التقرير السابق كان يعلن "✅ Pass" على حاجات لم تكن تعمل. هذا التقرير يستبدله.

## ما وُجد في المراجعة وتم إصلاحه

### صلاحيات (كانت تكسر معايير القبول)
| المشكلة | الإصلاح |
|---|---|
| أي مستخدم يعدّل `role` في صفّه ويبقى Admin؛ والتسجيل يقبل `role` من بيانات المستخدم | تعديل `profiles` للأدمن فقط؛ الدور من `app_metadata` |
| `process_handover_decision` بدون فحص للمتصل → أي حد ينقل أي مهمة | فحص المدير/الأدمن + نفس الفريق + عدم تكرار القرار |
| طالب النقل يختار `manager_user_id` بنفسه (حتى نفسه) | الإدخال المباشر ممنوع؛ `request_handover` تحدد المدير |
| `process_review_decision` الداخلية بدون فحص → الموظف أو العميل يعتمد | المراجع المعيّن فقط، ولا يعتمد نسخته |
| سياسة `FOR ALL` على النسخ → أي موظف يغيّر الحالة لـ "مشاركة مع العميل" | لا كتابة مباشرة؛ كل الانتقالات عبر دوال |
| صاحب المهمة يعدّل كل الأعمدة (المسؤول، الموعد) | التعديل المباشر للمدير/الأدمن؛ الموظف عبر `update_task_status` |
| أي موظف يبعت إشعار لأي حد | الإشعارات تُنشأ داخل الدوال فقط |
| الموظف يرى مهام/ملفات/تعليقات كل الفرق | نطاق الفريق |
| شرط العميل على `deliverables` يقارن `dv.id` بدل `deliverables.id` | تم التصحيح |
| العميل لا يرى أي ملف (البوابة دائمًا فاضية) | يرى ملفات النسخ المشاركة مع جهته فقط |

### أعطال وظيفية
- `.env.local` بدون `SUPABASE_SERVICE_ROLE_KEY` → الدعوات والتنزيل لا يعملان. **لازم تضيفه.**
- فورم "إسناد مهمة" يكتب أعمدة غير موجودة → يفشل بصمت. أُعيد كتابته.
- `/auth/signout` غير موجود → 404. تمت إضافته.
- `seed.sql` يفشل (عمود غير موجود + profiles قبل users). أُعيد كتابته.
- `datetime-local` كان يُفسَّر بتوقيت السيرفر (UTC) → المواعيد تتأخر/تتقدم ساعات. يُحوَّل الآن من توقيت القاهرة.
- علاقة `deliverables` ↔ `deliverable_versions` ملتبسة في PostgREST (مفتاحان) → الاستعلام يفشل. تم تحديد المفتاح.
- لا توجد واجهة رفع ملفات → دورة التسليم بلا ملفات. أُضيف `VersionUpload`.
- الأخطاء كانت `throw` → صفحة خطأ عامة. الآن رسالة عربية واضحة في نفس الصفحة.

### التصميم
- الشعار Bone على Sidebar أبيض (شبه غير مرئي) → Sidebar أخضر ثابت على اليسار.
- لون أخضر مخترع `#4A7C59` و HEX يدوي ومتغيرات غير معرفة → Tokens فقط.
- الحالات بالإنجليزي → نص عربي + علامة + لون معتمد.
- نص Clay صغير على Bone → نص Ink مع علامة Clay.
