SEO + GEO
RenderingStatic HTML for every page (SSG). Real <h1>–<h3>, one H1 per page.
VitalsLCP < 2.5s · INP < 200ms · CLS < 0.1 (75th percentile).
SchemaOrganization + ProfessionalService on home, Article/CreativeWork per case, FAQPage, BreadcrumbList.
Answer-firstEvery case opens with a TL;DR (Problem · Solution · Result) with numbers and sources.
Problem pages/problems/[slug] target what buyers ask: "unify brand across branches", etc.
AI crawlersrobots.txt allows GPTBot, ClaudeBot, PerplexityBot. sitemap.xml + llms.txt.
EntitySame name, description and links everywhere (Google Business, LinkedIn, Behance). "Last updated" on cases.
MetaUnique title (≤60) and description (≤155), OG image per case, descriptive alt text.
